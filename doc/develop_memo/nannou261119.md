# nannou 0.19 → 0.20 移行メモ

## 経緯

- Rust を 1.100.0 に上げたら build が通らなくなった
    - 原因: `objc2 0.3.0-beta.3.patch-leaks.3`（loopian → nannou 0.19 → winit 0.28 → objc2）
    - 新しい rustc でトレイト境界のチェックが厳しくなり、E0277 になる
    - 古いベータ版で、もう保守されていない
- 暫定対処（済み, commit 3f47ea5）
    - `vendor/objc2-0.3.0-beta.3.patch-leaks.3` に vendor し、`[patch.crates-io]` で差し替え
    - `ivar_forwarding_impls.rs` の DoubleEndedIterator で `nth_back` を削除、`next_back` の戻り値を `Option<Self::Item>` に
- objc2 だけを上げることはできない
    - winit 0.28 が `objc2 >=0.3.0-beta.3, <0.3.0-beta.4` に固定している
    - objc2 0.4 以降は API が互換でない
- 根本対処として nannou 0.20 へ移行する

## nannou 0.20 の概要

- crates.io に 0.20.0 が出ている（0.19 から長く止まっていたのは、Bevy への作り直しのため）
- Bevy 0.19.1 / winit 0.30 の上に作られている
- 見慣れた入口は残っている（皮を被せる方針）
    - `nannou::app(model).update(update).run()`
    - `app.draw()`, `app.time()`, `app.window_rect()`, `app.new_window()`, `app.main_window()`
    - 図形: `ellipse`, `rect`, `line`, `polyline`, `tri`, `no_fill`, `stroke`, `stroke_weight`, `x_y`, `w_h`, `radius`, `start`, `end`, `weight`, `rotate`
    - 数学・乱数・ノイズ: `pt2`, `vec2`, `map_range`, `random_range`, `nannou::noise`
- ただし下の Bevy が透けて見える部分がある

### 「ループの持ち主」が Bevy になる

- 0.19: nannou 自身がメインループを回し、`event` → `update` → `view` を順に呼ぶ。Model は nannou が持つ
- 0.20: Bevy がループを回す。Bevy は多数のシステムを並列実行するエンジンで、nannou はその一つ
    - Model は Bevy のリソース（倉庫）に預けられ、`update` などはそこから借りて呼ばれる
- その結果
    - **Model に `Send + Sync` が必須**（`mpsc::Receiver` は Sync でないので、そのままではエラー）
    - `App` にライフタイムが付く（`App<'_, '_>`）。ただし `fn update(app: &App, ...)` と省略して書ける
    - `view` で `Frame` を受け取らない。`draw` に書いておけば Bevy が描画する

## API の主な違い

| 項目 | 0.19 | 0.20 |
|---|---|---|
| update | `fn(&App, &mut Model, Update)` | `fn(&App, &mut Model)` |
| view (window) | `fn(&App, &Model, Frame)` + `draw.to_frame()` | `fn(&App, &Model)` |
| イベント | `.event()` で `Event::WindowEvent { simple: ... }` をまとめて受ける | window builder の `key_pressed` / `key_released` / `received_character` 等のコールバック |
| キー | `Key::LShift`, `Key::Key1`, `Key::Back`, `Key::Return` | `KeyCode::ShiftLeft`, `KeyCode::Digit1`, `KeyCode::Backspace`, `KeyCode::Enter` |
| 時間 | `app.time`（フィールド） | `app.time()` |
| 色 | palette の `Srgb<u8>`, `srgb::<u8>()`, `rgba()`, `Rgba` | Bevy の `Color::srgb_u8()`, `Color::srgba()` 等。`.rgba()` メソッドは `.srgba()` |
| テキストのフォント | `.font(Font)`（`Font::from_bytes` で作る） | `.font("ファミリー名")`。フォントは Bevy のアセット経由で読み込む |
| ウィンドウ設定 | `win.set_title()`, `win.set_inner_size_pixels()` | builder の `.title()`, `.size()` / `.size_pixels()` |

## Loopian の修正箇所

nannou を使うファイルは21個・約4,500行。大半は描画コードで、そのまま動く部分が多い。

| 箇所 | 内容 | 規模 |
|---|---|---|
| `loopian_app/src/main.rs` | builder を `.update()` のみに。`event` を window のコールバックに。`view` から `Frame` / `to_frame` を削除。`app.time` → `app.time()`。タイトル・サイズを builder で指定 | 小 |
| Model の Sync 対応 | `ui_hndr: Receiver<UiMsg>` を `Mutex` で包む。`GenerativeView` trait に `: Send + Sync` を付ける（`Box<dyn GenerativeView>` 約15か所はそれで済む）。Sync でないのは Receiver だけだった | 小 |
| `loopian_app/src/cmd/input_txt.rs` | `window_event(Event)` を `key_pressed` / `key_released` / `received_character` の3つに分ける。`Key::...` 約50か所を `KeyCode::...` に | 中（機械的） |
| 色（約46行） | `loopian_graphics/*`, `loopian_app/src/graphic/*` の palette の型を Bevy の `Color` に | 中（機械的） |
| フォント（約15か所） | `nannou::text::Font` を持ち回す方式から、ファミリー名の文字列に。`get_view_instance()` の引数や各 view の `font` フィールドも | 小〜中 |
| `loopian_graphic_api/src/resize.rs` | `app.main_window().rect()` の確認 | 小 |
| 図形・数学・乱数・ノイズ | ほぼそのまま | ほぼ不要 |

## フォントの問題と対処

- 0.20 のテキストはファミリー名しか指定できず、太さ・斜体を指定する手段がない
- フォントライブラリ fontique は name テーブルの 16番（Typographic Family）を優先し、なければ 1番（Family）を使う
- Loopian の JetBrains Mono は4つとも 16番が `JetBrains Mono` で区別できない

| フィールド | ファイル | 16番 / 17番 | 用途 |
|---|---|---|---|
| font_nrm | JetBrainsMono-ExtraLight.ttf | JetBrains Mono / ExtraLight | スクロールテキスト（入力行）、日付、graphic pattern |
| font_italic | JetBrainsMono-ExtraLightItalic.ttf | JetBrains Mono / ExtraLight Italic | スクロールテキスト（返答行） |
| font_bold | JetBrainsMono-SemiBold.ttf | JetBrains Mono / SemiBold | インジケータ、入力欄 |
| font_title | JetBrainsMono-ExtraBold.ttf | JetBrains Mono / ExtraBold | タイトル・サブタイトル |
| font_serif | Newsreader16pt-Regular.ttf | (1番) Newsreader 16pt | ロゴ（Loopian / by Kigakudoh / Ver.） |

- 方針: JetBrains Mono の 16番を、ファイルごとに別の名前に書き換える（例: `JetBrains Mono ExtraLight`）
    - Python の fontTools を使う（`pip install fonttools`）
    - 元ファイルは上書きせず、別名で保存する（例: `JetBrainsMono-ExtraLight-Loopian.ttf`）
    - 0番（著作権）と13番（ライセンス）は残す
- ライセンス（JetBrains Mono: SIL OFL 1.1）
    - Reserved Font Name の宣言はないので、名前を変えて配布してよい
    - 著作権表示とライセンスを添える → `assets/fonts/` に `OFL.txt`（JetBrains Mono 用）を置く
    - 改変版の宣伝に JetBrains の名前を使わない
    - 改変版も OFL のまま配布する
- New York は Apple のライセンスで再配布できないため、Newsreader に置き換えた（済み, commit a63ed4d）
    - `Loopian_Release/assets/fonts/` は次のリリース時に差し替える

## その他の注意

- ビルド時間: Bevy が入るため、初回のフルビルドは約2分。差分ビルドは数秒
- 非アクティブ時の更新頻度: Bevy は非アクティブ時に更新を落とす設定がある。表示がカクつくなら `app.set_unfocused_update_mode(...)` で変える（MIDI タイミングは elapse スレッドなので影響しない）
- `set_exit_on_escape(false)` に当たるものは 0.20 で要確認
